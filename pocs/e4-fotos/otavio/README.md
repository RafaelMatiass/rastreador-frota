# PoC Fotos Locais - Otavio

PoC isolada da Entrega 4 / Semana 9.

Demonstra a selecao ou captura de uma imagem e a copia para o armazenamento interno privado do aplicativo (`filesDir/poc_photos`). Nao usa Firebase nem nuvem.

## Como apresentar

1. Abra esta pasta no Android Studio.
2. Aguarde o Gradle Sync.
3. Execute no emulador ou dispositivo.
4. Toque em `Tirar foto` ou `Escolher da galeria`.
5. Mostre a imagem e o caminho local exibido na tela.
