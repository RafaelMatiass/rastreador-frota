# PoC Mapa da Frota - Otavio

PoC isolada da Entrega 5 / Semana 11.

Demonstra um mapa OpenStreetMap usando osM, um marcador de veiculo e uma sequencia de coordenadas simuladas. O marcador muda a cada quatro segundos.

## Como apresentar

1. Abra esta pasta no Android Studio.
2. Aguarde o Gradle Sync e o download do osM.
3. Execute com internet ativa para carregar os tiles do OpenStreetMap.
4. Mostre o marcador mudando de posicao e o status em transito/parado.

Nao precisa de API key do Google Maps.
